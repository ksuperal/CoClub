# influencer-web

**Status: scaffold only — functionality not yet designed.**

## Purpose (as discussed so far)

Frontend for influencers — the user-facing side of the Influencer component
(pairs with `../influencer-api`). Different user type from CoClub's `sme-web`
(SME brand owners), so this is a separate app rather than more pages bolted
onto `sme-web`.

Framework not yet decided — `apps/sme/sme-web` uses Next.js, but nothing requires
this one to match; pick whatever fits once real requirements exist.

## Not yet done

Everything — no framework set up, no pages, no Dockerfile, no dependencies, no
docker-compose entry.
