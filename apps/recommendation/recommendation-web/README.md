# recommendation-web

**Status: scaffold only — functionality not yet designed.**

## Purpose (as discussed so far)

Frontend for the Recommendation component (pairs with
`../recommendation-api`). A link/button in CoClub's `sme-web` app is meant to
route SME users into this app — simplest version is just a plain link to this
app's URL; a deeper integration (landing already logged in via shared Supabase
Auth) is a later concern, not yet wired up.

Framework not yet decided.
